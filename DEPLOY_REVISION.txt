Companion integrated Live2D V17.17: public/companion-character-stage-v1712.js + public/companion-character-stage-v1712.css?v=20260823-v17.17-integrated-live2d-background
Revision: 2026-08-23-v17.17-integrated-live2d-background
Behavior: the old CHARACTER STAGE floating card is removed. Live2D is mounted as an absolute background layer inside .uai-c-main, between the cinematic scene and the stable chat/header/composer UI.
Automatic role: entering companion mode automatically prepares the background role; no separate stage launcher is required.
Renderer stability: Pixi Application/WebGL renderer is created once per mounted companion session and reused by normal refreshes. mode-refresh/functions-ready no longer destroy and recreate the WebGL context.
Model switching: the current model remains visible while the replacement model loads; it is destroyed only after the replacement is ready. Same-character/same-model refreshes reuse the current model and renderer.
Removed regression trigger: the old manual reload button (data-v1712-reload) and old CHARACTER STAGE header/footer chrome remain removed from the active UI.
Context recovery: webglcontextlost is handled without immediate destructive recreation; webglcontextrestored schedules controlled recovery.
Interaction safety: pointer listeners are scoped to .uai-c-main through an AbortController and are released on stage teardown, preventing duplicate listeners across repeated entries.
Call presentation: data-v1713-call changes are observed alongside voice state so the same renderer changes placement for a call and returns to the normal background position on hangup.
Fallback: model/runtime failure degrades to a small transparent background avatar rather than a white stage card; core text chat remains usable.
